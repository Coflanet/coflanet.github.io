ContentOps Publisher는 티알스튜디오(TR Studio)가 자기 Threads 계정 세 개를 관리하려고 쓰는 내부 도구예요. 다른 사람이 로그인해서 쓰는 서비스가 아니에요.

ContentOps Publisher(이하 "도구")는 「개인정보 보호법」 등 관련 법령을 지켜요. 이 문서는 도구가 Threads에서 어떤 정보를 받고, 어디에 두고, 언제 지우는지 알려 드려요.

1. 도구를 쓰는 계정

도구는 티알스튜디오가 운영하는 아래 Threads 계정 세 개에만 연결돼요.

  • @iyumi.babyfood (이유미)
  • @coflanet.official (커플래닛)
  • @todok.keyboard (토독)

다른 사람의 계정으로 로그인하거나, 다른 사람의 계정을 대신 관리하지 않아요.

3. 보관 장소와 기간

  • 받은 정보는 티알스튜디오 업무용 컴퓨터에만 저장해요. 외부 서버나 데이터베이스에 올리지 않아요. 답글 초안을 쓸 때만 4장의 Anthropic에 보내요.
  • 검색으로 본 공개 글은 답글을 달 글을 고른 뒤 30일 안에 지워요.
  • 우리 글에 달린 답글과 우리 계정의 숫자는 성과를 비교하려고 1년 동안 보관한 뒤 지워요.
  • Threads 접근 토큰은 같은 컴퓨터에만 두고 다른 곳에 보내지 않아요.

5. 데이터 삭제

도구에 저장된 이용자님의 답글·공개 글을 지워 달라고 요청할 수 있어요.

  • 방법: team.trstudio@gmail.com으로 제목에 "ContentOps 데이터 삭제 요청", 본문에 Threads 사용자 이름을 적어 보내 주세요. 지울 글 주소가 있으면 함께 적어 주세요(선택).
  • 처리: 받은 날부터 10일 안에 답장하고, 30일 안에 해당 정보를 모두 지운 뒤 지운 사실을 알려 드려요.
  • Threads에 올라간 글 자체는 Threads에서 직접 지울 수 있어요. 도구는 Threads에 있는 다른 사람의 글을 지울 수 없어요.

6. 이용자의 권리

도구에 저장된 이용자님의 답글·공개 글을 열람하거나, 고치거나, 지워 달라고 요청할 수 있어요. 요청 방법은 5장과 같아요.

이 도구는 만 14세 미만 아동의 정보를 일부러 모으지 않아요. 알게 되면 바로 지워요.
