자주 묻는 질문

토독 키보드는 어떻게 켜나요?
  1. iPhone 설정 → 토독 → 키보드에서 '토독'을 켭니다.
  2. 같은 화면에서 전체 접근 허용을 켭니다(타건음을 들으려면 필요합니다 — 아래 질문 참고).
  3. 아무 입력창에서 키보드 아래 지구본 키를 눌러 토독을 고릅니다.
전체 접근은 왜 필요한가요?

iPhone 의 키보드는 앱과 따로 실행됩니다. 전체 접근 없이도 한글·영문 입력, 지구본 키, 삭제, 엔터는 모두 됩니다. 전체 접근을 켜면 키보드가 다음 네 가지를 합니다.

  1. 타건음 — 앱에서 고른 타건음과 소리 설정(볼륨·진동·무음)을 앱과 함께 쓰는 공간에서 읽어 소리를 냅니다.
  2. 붙여넣기 — 붙여넣기 단추를 누를 때만 클립보드의 글자를 읽습니다.
  3. 볼륨 노브 — 키보드 위 노브로 소리 크기를 바꿉니다(값은 키보드 안에만 둡니다).
  4. '켜짐' 표시 — 앱 설정에 '전체 접근 켜짐'이 보이도록 작은 표시(시각 숫자 하나)를 남깁니다.

토독 키보드는 입력한 내용을 저장하거나 전송하지 않으며, 인터넷 통신 기능이 없습니다. 전체 접근을 켜지 않으면 "전체 접근을 켜면 소리가 나요" 한 줄이 뜨고 붙여넣기 단추와 노브가 숨습니다.

키보드에서 소리가 안 나요.
  • 전체 접근이 켜져 있는지 확인해 주세요. 꺼져 있으면 키보드 위에 "전체 접근을 켜면 소리가 나요"가 보입니다.
  • 토독 앱을 한 번 열어 주세요. 앱이 조립한 소리를 키보드에 넘겨줍니다.
  • 키보드 위 노브의 볼륨과 iPhone 음량을 확인해 주세요. 키보드 소리가 '시스템'으로 되어 있으면 무음 모드에서 꺼집니다.
앱에서 소리가 안 나요.

앱 설정에서 무음 모드가 꺼져 있는지, 볼륨이 0 이 아닌지 확인해 주세요.

로그인이 있나요?

없습니다. 토독은 회원가입·로그인 없이 바로 씁니다. 내 보드·설정·두드린 기록은 모두 이 기기 안에만 저장되고, 서버로 보내지 않습니다.

폰을 바꾸면 보드를 옮길 수 있나요?

지금 판에서는 옮길 수 없습니다. 내 보드·설정·기록이 이 기기 안에만 있어서, 새 폰에서는 처음 보드부터 시작합니다. 기기 사이 옮기기는 다음 판에서 검토하고 있습니다.

내 데이터를 지우려면 어떻게 하나요?

앱을 지우면 이 기기에 저장된 내 보드·설정·기록이 모두 지워집니다. 서버에 남는 데이터는 없으므로 따로 탈퇴하거나 삭제를 요청할 필요가 없습니다.
