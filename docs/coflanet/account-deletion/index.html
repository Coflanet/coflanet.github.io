1. 계정 삭제

Coflanet 앱 내에서 직접 계정을 삭제할 수 있습니다.

삭제 방법

1앱 실행 후 하단 탭에서 마이 탭을 탭합니다.

2마이 화면의 설정을 탭한 뒤, 설정 화면 하단의 회원탈퇴를 탭합니다.

3확인 창 두 번(탈퇴하기 → 네, 탈퇴할게요)을 거치면 계정이 즉시 삭제됩니다.

삭제되는 데이터

데이터 유형처리보관 기간
계정 정보 (로그인 계정 · 이메일 또는 소셜 로그인 식별자, 이름)즉시 삭제없음
커피 취향 설문 결과 (저장된 취향 전부)즉시 삭제없음
저장된 커피 원두 목록즉시 삭제없음
커피 추출 레시피즉시 삭제없음
추출 기록즉시 삭제없음
찜한 원두즉시 삭제없음
커피 저널 (기기에 저장된 시음 노트)즉시 삭제없음
계정 삭제 시 위 데이터가 서버(Supabase)와 기기 로컬 저장소에서 영구적으로 삭제되며, 복구할 수 없습니다. 계정과 무관한 기기의 화면 설정(라이트 · 다크 모드)은 앱을 삭제할 때 함께 지워집니다.

2. 데이터 삭제 (계정 유지)

계정을 삭제하지 않고도 앱 내에서 개별 데이터를 삭제할 수 있습니다.

삭제 가능한 데이터 및 방법

원두 목록 삭제: 원두 탭 > 편집에서 원두를 골라 삭제합니다. 그 원두에 저장한 추출 레시피도 함께 삭제됩니다.

추출 기록 삭제: 마이 > 추출 기록에서 기록을 삭제합니다.

커피 저널 삭제: 마이 > 커피 저널에서 노트를 삭제합니다.

찜 해제: 원두의 하트를 다시 눌러 찜을 해제합니다.

전체 로컬 데이터 초기화: 앱 삭제 후 재설치 시 기기 내 모든 로컬 데이터가 삭제됩니다.

데이터 삭제 범위

데이터 유형개별 삭제방법
커피 원두 목록가능원두 탭 > 편집에서 삭제
추출 레시피가능해당 원두를 삭제하면 함께 삭제
추출 기록가능마이 > 추출 기록에서 삭제
커피 저널가능마이 > 커피 저널에서 삭제
찜한 원두가능하트를 다시 눌러 해제
취향 설문 결과불가다시 하기를 하면 새 취향이 추가되고, 이전 취향은 계정 삭제 시 함께 삭제
계정 정보불가계정 삭제 필요
