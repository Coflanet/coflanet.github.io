계정 및 데이터 삭제 안내

이유미(iyumi) 이용자는 언제든지 본인의 데이터와 계정을 삭제할 수 있습니다.

이유미는 로컬 우선(local-first) 앱입니다. 아기 정보·섭취/알레르기 기록·사진 등 대부분의 데이터는 이용자 기기에만 저장되며, 앱을 삭제하면 함께 사라집니다.

1. 앱에서 직접 삭제 (가장 빠름)

  • 개별/전체 기록 삭제: 앱 내 기록·프로필 화면에서 직접 삭제할 수 있습니다.
  • 전체 데이터 삭제: 기기에서 앱을 삭제(제거)하면 이 기기에 저장된 모든 로컬 데이터가 파기됩니다.

2. 계정(로그인) 삭제 요청

카카오 또는 Apple 계정으로 로그인하신 경우, 서버에 저장된 계정·동기화 데이터 삭제를 아래 방법으로 요청할 수 있습니다.

  1. 아래 이메일로 "계정 삭제 요청"이라고 제목을 적어 보내주세요.
  2. 본인 확인을 위해 로그인에 사용한 방식(카카오/Apple)과 가입 시 사용한 이메일을 함께 적어주세요.
  3. 접수 후 처리 결과를 회신드립니다.
📧 삭제 요청: team.coflanet@gmail.com
